# FlightHelmet

Khronos glTF Sample Assets, `Models/FlightHelmet/glTF` at commit
[4995a638](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/4995a638c96dbc94376d3d6164e70fee3ac7f7a2/Models/FlightHelmet).
The model files are **CC0 1.0**; `LICENSE.md` (Khronos's own text, CC-BY 4.0) is kept as published. Used by the
`golden: flight helmet` tests (docs/specs/first-real-scene/spec.md). `FlightHelmet.gltf.meta` sets
`max_texture_size` to 512 to keep cooking and the WARP golden fast.
