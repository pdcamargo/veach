- **VCH-047** Windows GPU runner script — *process* — Dropped: there is no Windows machine, and Windows is verified in hosted CI only ([ADR 0032](../adr/0032-windows-verified-in-hosted-ci.md)).
- **VCH-003** MCP server v0 — *agents* — `--mcp` serves MCP over stdio: `query_entities`, `get_component`, `set_component`, `spawn_entity`, `step_frames`, `screenshot`, `render_graph_plan`, `gpu_timings`, sandboxed transactional `eval`. Schemas come from reflection; errors carry codes and did-you-mean hints. `load_scene` moves to VCH-027. [spec](../specs/mcp-server/spec.md)
- **VCH-041** Parameter-block layout checks — *render* — Each shader's parameter block is reflected (Slang, HLSL layout) into `<ns>::layout::<stem>`; `static_assert(rhi::parameters_match<T>(...))` compares names, order, offsets and sizes at compile time. The shader build rejects `float3`/3-row matrices. The hygiene check requires a layout check for every shader with parameters. [ADR](../adr/0027-resource-binding-model.md)
- **VCH-045** Frames in flight — *rhi* — N frames in flight (default 2) on a shared `SubmissionTracker`: monotonic submission ids, per-slot fences, per-frame TLAS instance buffers, and fence-tracked retirement for `destroy()`. Pooled transients sync with their previous frame (`Barrier::discard`). [ADR](../adr/0030-frame-and-sync-model.md)
- **VCH-010** First light: RHI v0 and render graph v0 — *render* — Metal backend with buffers, textures, samplers, graphics and compute pipelines, BLAS/TLAS build and refit, swapchain, offscreen targets, readback, Metal validation in debug, and GPU errors logged at error level. Bindless through `DescriptorHandle`. The render graph derives order, culling and barriers. A rasterized triangle and a ray-query triangle. [spec](../specs/first-light/spec.md)
- **VCH-013** Golden-image tests — *tools* — `--screenshot`, `veach imgdiff` (NVIDIA FLIP), goldens in Git LFS, an `update-goldens` target, and a skip on unsupported GPUs (`VEACH_REQUIRE_GPU=1` makes it a failure). [spec](../specs/first-light/spec.md)
- **VCH-001** Repository bootstrap — *process* — Skeleton engine: init/shutdown order, fixed phases, Flecs barrel, reflection everywhere, command buffer, Luau API v0 with generated types, asset system with `.meta` ids, SDL3 and headless platforms, null/Metal/DX12-stub RHI, extraction boundary, the lab hello world, CI, and the docs and process files. [specs](../specs/README.md)
